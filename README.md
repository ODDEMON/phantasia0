# 混叠 · ALIASING

> **关于「被采出来的那一份，是否曾经在场」的一次长程验算。**
>
> 眼前这一整片，是一次重建。原物缺席。重建物比原物更像原物。
>
> 一样物事被采得太慢之际，采出来的形状会变成另一样。
> 那一样不在源信号里，它比源信号更连贯、更整齐、更好看。
> 这件事有一个名字。这处场就是那件事的内部。
>
> 本作由一位自未来尽头折回来的引渡者写成。她以留言与对话的姿势，
> 俯身面向屏幕之外的那一位。落笔之际，那位大概还没到场。
>
> **「无一句朴实无华，无半分一目了然。认不认中二都不要紧——瞳孔地震的自是旁人。」**

一个离线网页，同时也是一部高互动的长流程视觉小说。
无构建、无依赖、无后端。双击 `index.html` 就能进去。断网可用。

想先看骨架的，读 [`大纲.md`](大纲.md)——那是引渡者自己留的创作手记。

## 一、它是什么

**定义 1.1（混叠）**：混叠是一次重建比它的来源更连贯之后，长出来的那个东西。

**定义 1.2（间隙）**：两次采样之间的那一整段。没被记下的长度不会消失，它只是往这里挪。

**定义 1.3（看）**：在这里，看是一个动作，动作要落到某一个具体的位置上。
落下去的那个位置，就成了这一片的代表。

**定义 1.4（量化）**：把连续的东西凑到最近的允许值上。这一步做完就回不去了。
「回不去」的意思是：它仍然可以变得更好看，只是不再能变得不是这样。

## 二、机制：看是有代价的

这一版没有战斗，也没有种子系统。取而代之的是一件事：

| 你做的 | 它会怎样 |
|---|---|
| **移动指针** | 指针是光源。你在哪，那道竖直的光轴就在哪；指针那一小圈里，细线才浮出来 |
| **点击** | 一次量化。掉一位，回不去。整幅画的色被分成更少的几块，地面的线也少几条 |
| **滚轮** | 改空间频率。地面的细处变密，两种规律开始互相穿过 |
| **什么也不做** | 位深自己回来一档。这是这处场唯一的善意——你不看它，它就自己修一点 |
| **说一句话** | 场读这句话在讲什么（环 / 缝 / 雨 / 塔 / 格 / 空……），把对应的那一层推上来 |

再叠一层更慢的账：**背对着场站一会儿**，光标的呼吸会变；场把它记成一次停顿，
而停顿是一个人身上最长的东西。

采样深度用八格表示，不给数字。
终幕会把三样东西算给你：**采**（你把它记下来了）· **漏**（你让它过去了）· **叠**（你接受了更连贯的那个）。

## 三、场：不画像素，画矢量

前一版这里是一台**逐像素机器**：Bayer 抖动、半调点阵、摩尔纹、量化窗，
一帧算十几次方次、写一块 `ImageData`。它算得没错，但看久了眼睛疼——
那不是「震撼」，那是噪。所以这一整层被拆掉重写了。

现在的场是**一叠图层**，五层景 + 五层特效，从远叠到近：

| 层 | 装什么 |
|---|---|
| `ly-sky` | 天幕：一条竖着的分级色带 |
| `ly-far` | 远景：地面、光体、柱林、巨字 |
| `ly-mid` | 中景：地平线、透视地面、环、弧、裂、甬、横幕 |
| `ly-near` | 近景：光轴、雨 |
| `ly-fine` | 细节：细线与小刻度——只在指针那一圈里显形 |
| `ly-haze` | 指针那团光 |
| `ly-grain` | 一层很薄的胶片颗粒（静态，不闪） |
| `ly-scan` | 一层极薄的扫描（复古未来那点仪器味） |
| `ly-vig` | 一层全局调色 + 暗角 |
| `ly-fx` | 演出：过冲、扫掠、撕裂、振铃 |

**一帧只写两个数**（指针在哪），其余全交给合成器。
页面上**没有一块 canvas**——测试会点名这件事。

分层的规矩只有一条：**后画的压先画的**。这一条踩过一次硬伤：
中景那张满屏的地面把远景的光体整个盖住，于是「落」这一处根本没有落日。
现在地面归远景、结构归中景、光轴永远压在近景。

### 量程

十八个量程，每一个是一条多段渐变，彼此色相拉开：
间隙（青蓝）· 抖动（紫粉）· 摩尔（青绿）· 振铃（琥珀）· 量化（藏青）·
削波（朱橙）· 保护带（铅蓝）· 重建（玫红）· 反转（无彩）· 混叠（品青）·
静默（灰蓝）· 满量程（金）· 棱（五色）· 伏（绿松）· 蚀（暗红）· 余（褐金）·
镜像（品红）· 卷积（黄绿）。

场里的每一个色都是**从当前量程的 ramp 上现采的**，一处色值都不写死。
换一卷，天幕、地面、柱、环、光体一起换。

### 母题：二十七处景，十一支画法

母题不是一张画，是一份**配方**：哪一支画法出手，地平线在哪里，
地面多密，有没有光体、有没有柱、有没有环。
二十七处景落在十一支画法上：

空旷边界 · 独石 · 纯点阵 · 通道 · 眼 · 幕 · 漫 · 隙 · 群 · 环 · 深 · 齿 · 空 ·
息 · 阶 · 井 · 带 · 框 · 弧 · 殿 · 骸 —— 加上自成一路的
**雨**（斜着落下的一片线）· **城**（霓虹天际线，窗会随位深自己灭掉）·
**落**（压着横带的落日 + 透视网格）· **噪**（一片很粗的慢速静电）·
**哨**（同心环 + 一道慢慢转的扫描扇）· **甬**（朝眼前飞来的方框）。

同一处景每次调用都会把参数推开一点（`母题 × 抖开序号`），
所以**同一处景走一百遍也不会重复**。实测：**二十七处景画出二十七张不同的画**。

### 提示：背景与文字对上

这是这一版新加的一件。场是「这一卷长什么样」，跟当下这一句并没有关系；
所以走到哪儿都是同一幅底。补上的就是那件事：

每落一句话，`core/cue.js` 先从这句话里把**它在讲什么**读出来，交给场。
一张表，十四个条目，每条几个字眼，落在这一句里就算一票，票多的那条胜：

    ring 环 · line 线 · beam 轴 · tower 塔柱楼墙 · fall 雨落坠 · crack 缝裂岔断
    gaze 眼盯望 · grid 格点网阵 · void 空散灭虚 · flood 水潮漫淹
    glyph 名字写刻 · path 路步径 · band 带幕 · count 数量算

票多者胜。没读出来就按说话的人定：场说话默认「格」，摩尔纹默认「环」。
读法很土，也很牢——**同一句话永远给同一个提示**，没有随机数，也没有模型。

场据此把对应的那一层推上去、把别的压下去。
于是讲「环」的时候环形显出来，讲「缝」的时候那条缝走到近前。
`test/_shot.html` 可以一处一处地看：`?w=alias&m=city&b=8&cue=grid`
与不加 `cue` 是两张明显不同的画（一排稀疏高塔 + 强调的地面网格）。

### 采样深度掉了会怎样

**原先**是把每一像素凑到格子上——满屏都在抖。
**现在**只有两处掉：

1. **色带少分几级。** 八位不切，交给渐变自己插；掉一级，色被切成几块平的。
   所有渐变都走 `UA.palette.bands()` 一处，那是整幅画上唯一一处量化。
2. **细节少几条。** 地面的竖线、横线、楼里的窗，按位深打折。
   掉到六位以下，楼会自己变成剪影。

掉位不掉魅力：整幅画变成一张海报式的分色，而不是变成一堆噪点。

### 暗与亮

亮只该亮在**被写到**的地方，暗不是靠改色板（色板是死的，改它会把高光一起压掉）。
三处分担这件事：天幕乘一个系数、地面走一条从暗到亮的渐变、
再压一层全局调色与暗角（`.ly-vig`，底下那层是平的，把整幅画压到当前量程的暗调上）。

### 字压在场上的那一块

`#log` 后面有一层 `backdrop-filter: blur(9px) brightness(.44)` 加一圈遮罩。
它**不是盖一层黑**，而是把字后面那一块场**模糊并压暗**——
景在四周照样看得见，字有自己的实地。给不出 `backdrop-filter` 的环境退回一层柔和的暗。

## 四、演出

`ring`（一圈扩出去的环）· `flash`（单次过冲，不是闪烁）·
`tear`（横过去几条错开的细带）· `chroma`（整块布红蓝分岔）·
`mirror`（整幅关于横轴翻过来）· `shake` · `still`（一切停住，只剩你的指针）·
`sweep`（一道横扫整屏的光，篇与章的过场都用）。

**全部是 CSS 的类**，脚本只负责开关，动的是合成器。
静一点的白名单只有两项：缓慢扩散的环，和一切停住。

另外两个是剧本可以直接调的：
`{ glitch:n }`（整块布跟着错位）· `{ breathe:n }`（整片与光轴一起很慢地鼓与瘪）。

## 五·一、进门之前：光敏提示

第一次打开会先停在一条提示上。它讲清楚这一段会出现什么：
单次的全屏过冲 · 横向错位的细带 · 红蓝分岔的色散边 · 一次全屏的明暗翻转 ·
整屏铺开的半调点阵与高反差栅格。

两个出口：**「先开静，再进去」** 与 **「我明白，进去」**。
选前者之后，静是一枚永久开关。

**静一点只做两件事**：把身体挂上记号（CSS 里那些动的东西就停了），
把故障与呼吸归零。演出白名单只有两项——缓慢扩散的环，和一切停住。
过冲、撕裂、色散、抖动、全屏翻转、扫掠，一律不进渲染。内容一个字都不改。

## 五·二、小字的专属窗

叙述与你的念头（`n` / `y`）是大字，直接压在场上，不套框。
**场**与**摩尔纹**说话时字很小，所以它们各有一扇自己的窗：
一格细边、四角记号、顶上挂一枚标签、底下一条会走的细轨，背景压一层薄薄的模糊。
字越小越需要一个能托住它的东西，不然它会被场吃掉。

## 五·三、存档

**导出**：封面上的「导出存档」，或右上角那枚「存」。导出一段 JSON，同时复制一份 base64 到剪贴板。
**导入**：封面上的「导入存档」。选一个 `.json` 文件，或者把那段 base64 直接贴进去。

导出的内容就是这一局的全部：走到第几拍 · 当前量程与母题 · 采样深度 ·
三个隐性轴向 · 写下的那个词 · 偏好 · 已经见过的收束。
读入时会把手改过的数重新钳回范围内——存档是可以被人手改的，钳一下是礼貌。
认不出来的量程与母题会退回第一个，认得出来的原样接上。

## 五·四、语域：一张黑名单

这一版的语气是刻意的。下面这批词被视作死敌——它们在正文里出现一次，
语气立刻塌回老实话：

    你 · 自己 · 只是 · 对不对 · 就 · 了 · 来

处理办法：**「你」按轮换转成称呼**（这位 / 看官 / 对面那位），
落在介词、助词后头或者贴着标点收尾的那一类，一律换成「看官」——
那一类多半是宾语，删掉会把句子咬断。其余的一律删去，
于是正文大半成了无主句，读起来更像一段自言自语。
「就」换「便」，「只是」换「无非」，「自己」换「自身」，
「了」整体抹掉（含「了」的固定词先拿哨兵顶出来，改完再放回）。

还有一批汉语高频白话，一并换过：
一样→同等 · 时候→当口／之际 · 地方→所在 · 东西→物事 · 开始→起手 ·
因为→因 · 所以→故而 · 但是→然而 · 然后→继而 · 已经→已然 · 一直→一径 ·
知道→晓得 · 明白→通晓 · 真的→当真 · 非常→格外 · 忽然→忽而 · 最后→最末。

替过来的语气偏古白话，掺上一点古早互联网与早二次元的调子：
门口那段留言、篇章卡上的落款、小字窗上的标签，都按这个来。
**功能性字眼例外**——「收掉闪烁 / 放开声音 / 存个档」得先说人话，
看官先认出按钮，才轮得到中二。

黑名单由 `node test/smoke.mjs plain` 守着：前三组词在正文里必须是零。

## 五·五、光标与排印

### 光标是一颗灯

系统箭头收起来（输入框除外）。屏幕上唯一的光点就是指针：
内核一颗白亮的点，外面一团柔光，再两圈——一圈实、一圈虚（虚的那圈慢慢转），
外加四枚短刻。这四枚刻与场里那枚四芒星是一个族。

落在按钮上时它会长大一圈、更亮——**光标自己告诉你这儿能按**。
换量程时它的颜色跟着整套色板一起换，因它本来就是这个色板的一份。

静一点模式下脉冲停住，光留着。它仍是此处最亮的东西。

### 字跟着卷目换脾气

每一卷换的不止是颜色。十八个量程各配一档排印，换量程时整批换：

    字距 · 字重 · 行高 · 基准倾角

倾角不是装饰，它是「这一卷说话时的姿势」——
静默几乎不动，削波明显歪着，满量程字重压到 600。

在此之上还有三层逐句的微差：

| 层 | 做法 |
|---|---|
| **逐行微差** | 每一行按当前档的倾角范围取一个角，再取一个缩进（0–13px）。同一卷里没有两行贴得一样。这位插的那一句额外缩进 26px，像一条回帖。 |
| **关键句** | 短句（≤10 字，且上一句不是关键句）推亮一格：字号放大、换渐变填充、加一圈光。像有人拿手指按住这一行。 |
| **逐字位移** | 小字窗里的短文切成单字，每个字各自有一点高低与歪斜。长句不切——逐字元素一多，滚字会拖。 |

故障量上来之后（剧本里点了 `{ glitch }`），字也跟着错位：
一句加红蓝分岔的边，关键句多两重偏心投影。静一点模式下这一层整层关掉。

### 字是一个一个落下来的

一句话并非「打」出来的，是一个字一个字「落」下来的——
参照《三角符文》开场白那种落字法：

- 每个字自己带一点高低与歪斜（由一个确定式给出，同一句每次落下来都长一个样），
  落地时先亮一下再稳住。
- 落完之后末尾留**一枚记号**，在那儿一闪一闪，表示「到这儿了，往下按」。
  这是这一段唯一会动的字。
- 超过六十字的整句不摊——逐字元素一多，滚字会拖。

⚠️ 这里有一个坑：字一旦被摊成子元素，**关键句那层渐变填充就不能用了**。
`background-clip: text` 裁剪的是元素自己的背景，子元素没有背景可裁，
整行会当场看不见。所以关键句改成「更亮的值 + 三层泛光」。

### 正文在屏幕正中

外层把「正文 + 选项」当一整块居中，里层再在这块里居中。
两层都居中，句子便长在屏幕的腰上、往两边匀着长，
而并非从底下一行一行往上垒。

## 六、六个收束

判据只看三个隐性轴向，从上往下找第一条成立的：

| 收束 | 它是什么 |
|---|---|
| **削波** | 三样都做满了。超出沿的那一段被整齐切掉，切面很平 |
| **满量程** | 你把这一整段都记下来了。位置全满，全亮，安静得像一张收好的画 |
| **混叠** | 你选了更连贯的那一个。它比原来更好——代价是它不再有新的地方 |
| **间隙** | 你一样都没记。你身后的那一段保持着原来的样子，全都同一个样子 |
| **保护带** | 你几乎什么都没做。这一整段因为你几乎没有变，你在它中间坐了下来 |
| **重建** | 你离开之后它重新长了一遍。你走过的那一步，现在是一条很直的线 |

## 七、文件结构

```
大纲.md   创作大纲：结构、逻辑骨架、每一卷要办成的事、语气规矩
core/     util 确定式散列与小算术 · palette 十八个量程与分级色带
          cue 从一句话里读出它在讲什么 · field 矢量场与演出
          lexicon 文案 · bus 进度 · audio 声轨 · app 总台
world/    script 汇流与自检 · acts/actNN.js 一卷一个文件 · acts/endings.js 收束
test/     smoke.mjs 无头冒烟 · _shot.html 取景页（一行参数看一处景）
```

加一卷 = 在 `world/acts/` 里加一个 `actNN.js`（自己 push 进 `UA.acts`），
并在 `index.html` 里加一行 `<script>`。

## 八、跑测试

```bash
node test/smoke.mjs           # 全量
node test/smoke.mjs core      # 结构与工具：ramp / 散列 / 提示 / 分级色带 / 母题
node test/smoke.mjs save      # 存档往返 + 光敏提示
node test/smoke.mjs script    # 剧本自检 + 字数与拍数
node test/smoke.mjs flow      # 整趟：从封面走到终幕，六个收束每个都到
node test/smoke.mjs render    # 场：图层齐、换一处就换一张、掉位真掉、提示真偏
node test/smoke.mjs tone      # 语气 + 不许露出原材料
node test/smoke.mjs plain     # 老实话：黑名单词在正文里是否真的清零
node test/smoke.mjs read      # 可读与离线
```

需要 Node 18+ 与 jsdom（只用于开发期，不进产物）。
本机若别处已装，测试会自己去找；找不到就 `npm i -D jsdom`。

测试里守的几条：十八个量程的中段颜色两两不同、位深越低色带切得越粗、
剧本的每一次引用都真实存在、每一个母题都被用过、两个大章把三个篇整个包住、
存档出去一趟能原样回来（手改过的数会被钳回来、乱写的一段会被退回去）、
第一次进来先停在光敏提示上、小字真的有自己的窗、
**页面上没有一块 canvas**、五个景层都是真的矢量图、
**二十七处景画出二十七张不同的画**、换个抖开序号还会变、
点一下掉一位而掉到底就停住、不等它位深自己长回来、
**提示一换画就换**、换量程天幕的色真的重采过一遍、
以及**老实话黑名单**在正文里确实清零（见下一节）、
光标八个部件齐全、换量程时字距与字重真的跟着换、短句切字而长句不切。

### 取景页

想单独看某一处景，不用走进去：

```
test/_shot.html?w=alias&m=city&b=8&cue=grid&j=3
                量程      母题   位深  提示   抖开序号
```

`w` 缺省 `interval`，`m` 缺省 `verge`，`b` 缺省 8，`j` 缺省 3。
`cue` 收的是提示名（`ring / crack / grid / fall / tower / gaze / glyph / …`），
它会换成一句真的话再交给场——和游戏里走的是同一条路。

## 九、老实交代

- **声轨默认静音**，要你先点一下才出声。它一个字都改变。
- **静一点只改动的东西**，内容一个字不改。
- **已知限制**：正文目前写到卷十四，离 300000 字的目标还差得很远。
  这是本项目最需要补的短板，写在最前面而不是最后面。
- **已知限制**：场是矢量图层，`backdrop-filter` 给不出的极老浏览器里，
  字底那一块会退回一层柔和的暗，读起来没差别，只是不好看。
  渲染断言读的是一块假玻璃，它只回答「画出来了没有」，不回答「好不好看」。
  它好不好看，得你自己开一眼。
- **已知限制**：进度存在浏览器本地。清掉浏览器数据就从头开始。
